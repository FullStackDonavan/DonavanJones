## What it does

Christian Reels turns ideas into finished, original vertical videos on hardware I own. It writes a script, makes artwork, narrates, renders a 1080×1920 MP4 with burned-in captions, runs quality checks, and then **waits for a person to approve it**. It never posts anything on its own: approved videos become packages (MP4, cover, captions, per-platform titles and a suggested posting time) on a posting calendar.

## How it's built

- **One Temporal workflow per video.** Stages run on separate task queues; the AI queue runs one stage at a time across every video, with spacing between model calls and an exponential cooldown after errors. Failed stages wait on durable Temporal timers (5 minutes up to 6 hours, at most 4 tries), so retries survive restarts and deploys.
- **Scripture is never generated.** A verse section stores only a reference; its words always come from the Bible database, and an unknown reference is refused. QA uses Whisper to confirm the narrated verse matches the text.
- **Hardware split.** Scripts on a Jetson (llama3.2:3b), vision checks on a second Jetson (qwen2.5vl:3b, with an RTX 3090 fallback), SDXL and Wan 2.2 on the RTX 3090, FFmpeg rendering and graphics in a Python media worker, and Kokoro TTS and Whisper STT on gpu-worker-2. All files live in the homelab MinIO bucket.
- **Editing.** A storyboard editor for text, sections and narration voice; per-scene art changes by new prompt, inpainting, upload, magic eraser, background replacement or 2× upscale.

## Status

Runs on the homelab K3s cluster. The full app run (idea → script with a verified verse → LoRA art → render → QA → review) passes, as do the unit tests, the Python worker tests and a phone-width Playwright sweep. Posting to YouTube, Facebook, Instagram and TikTok is built from the official APIs and guarded by unit tests, but **has not been run against real accounts yet**, and Spanish versions with the real models still need a Spanish Bible imported.
